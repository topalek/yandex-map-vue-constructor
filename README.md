# Карта — редактор меток и линий

Небольшое веб-приложение на Vue 3 и Яндекс.Картах (JS API 3.0): можно расставлять
метки, рисовать линии, измерять длину по карте и переключать слои
(схема / спутник / гибрид).

## Возможности

- **Метки**
  - добавление кликом по карте;
  - перетаскивание;
  - типы: БС, БС МБТ, ТКД, камера, шкаф, муфта, абонент, опора, кросс, другое
    (иконки [Hugeicons](https://hugeicons.com/));
  - цвет, название и описание в боковой панели; выбранный цвет окрашивает
    иконку метки, а не её фон; при наведении на метку показывается всплывающая
    подсказка с названием и описанием;
  - удаление.
- **Линии**
  - режим «Линия»: клики по карте добавляют точки, «Завершить» сохраняет линию,
    «Точку назад» убирает последнюю;
  - цвет, толщина и тип линии (сплошная, пунктирная, точечная,
    штрихпунктирная);
  - клик рядом с линией выбирает её и открывает панель настроек;
  - длины сегментов и общая длина показываются при рисовании.
- **Слои карты**: схема, спутник и гибрид (спутниковый снимок + подписи и POI).

## Стек

- [Vue 3](https://vuejs.org/) (Options API, обычные `.vue`-компоненты);
- [Vite 8](https://vite.dev/);
- [vue-yandex-maps 3](https://vue-yandex-maps.vercel.app/) — обёртка над
  Yandex Maps JS API 3.0;
- [Hugeicons](https://hugeicons.com/) (`@hugeicons/core-free-icons`,
  `@hugeicons/vue`) — иконки типов меток;
- Bootstrap 6 (alpha) — CSS и JS подключены с CDN в `index.html`.

## Запуск

```bash
npm install
```

Создайте `.env` в корне и укажите ключ API Яндекс.Карт
(шаблон — `.env.example`):

```dotenv
VITE_YANDEX_MAP_API=ваш-ключ-api
```

```bash
npm run dev
```

Приложение откроется на <http://localhost:5000> (порт задан в `vite.config.js`).

### Скрипты

| Команда           | Что делает                              |
| ----------------- | --------------------------------------- |
| `npm run dev`     | дев-сервер Vite с горячей перезагрузкой |
| `npm run build`   | production-сборка в `dist/`             |
| `npm run preview` | локальный просмотр собранной версии     |

## Как пользоваться

1. **Метка** (режим по умолчанию) — кликните по карте, чтобы поставить метку.
   Она сразу выделяется, рядом открывается панель: вид, цвет, название,
   описание, удаление. Метку можно перетаскивать мышью.
2. **Линия** — нажмите «Линия» в тулбаре и кликайте по карте. Подсказка сверху
   показывает число точек и суммарную длину. «Точку назад» удаляет последнюю
   точку, «Завершить» создаёт линию и открывает её настройки.
3. **Слои** — кнопки «Схема», «Спутник», «Гибрид» в правом верхнем углу.
4. Чтобы выбрать линию в режиме меток, кликните рядом с ней (допуск зависит от
   текущего зума).

## Особенности реализации

- **Спутниковый слой.** В `vue-yandex-maps` 3.0.x нет компонента
  `YandexMapDefaultSatelliteLayer`, поэтому он написан локально поверх
  `ymaps3.YMapDefaultSatelliteLayer`.
- **Гибрид.** Спутниковая подложка дополняется растровыми тайлами подписей
  (`YMapTileDataSource` + `YMapLayer`), URL тайлов собирается с ключом из
  `VITE_YANDEX_MAP_API`.
- **Данные хранятся только в памяти.** Метки и линии не сохраняются между
  перезагрузками страницы — бэкенда и localStorage пока нет.
- Стартовый центр карты задаётся константой `INITIAL_CENTER` в
  `src/components/Map.vue`, список типов меток — `MARKER_TYPES` там же: каждой
  типу сопоставлена иконка Hugeicons, а цвет метки передаётся иконке через
  свойство `color`.
- Палитры и типы линий — константы `MARKER_COLORS`, `LINE_COLORS`, `LINE_TYPES`.

## Известные ограничения

- Режим «линейки» (измерение расстояний без сохранения линии) реализован в
  `Map.vue` (`activateRuler`), но кнопки в тулбаре у него пока нет.
- Нет сохранения/экспорта данных и отмены действий (кроме удаления последней
  точки при рисовании линии).
